Información de privacidad

Uso personal y acceso limitado a archivos.

Esta política describe el uso de información de Google por IBKR Swing Scanner. La persona titular de la aplicación administra el proyecto para su propio uso.

Información y finalidad

La integración de Google en desarrollo se destina a crear, leer y actualizar archivos del proyecto: copias del histórico OHLCV, metadatos de integridad, informes de ejecución y una hoja técnica de candidatos. El programa no necesita datos de cuentas bursátiles, saldos, posiciones ni órdenes para esta integración.

El permiso solicitado es https://www.googleapis.com/auth/drive.file. Permite trabajar con archivos creados o abiertos con la aplicación. No se solicita el permiso de acceso general a Drive.

Autorización y protección

Google gestiona el inicio de sesión y el consentimiento. La aplicación no recibe ni almacena la contraseña de Google. Los tokens permiten acceder a los recursos autorizados.

El asistente de escritorio cifra las credenciales guardadas localmente mediante Windows DPAPI, vinculándolas al usuario de Windows. Las credenciales destinadas a la futura ejecución automática se almacenarán en GitHub Actions Secrets. Los tokens y las claves se excluyen del repositorio y de los registros.

Las comunicaciones con las APIs se realizan mediante HTTPS. Las copias usan huellas de integridad y pruebas de recuperación. El usuario controla los permisos de los archivos en Google Drive.

Servicios y divulgación

Google procesa la información alojada en Drive y Sheets. GitHub aloja el código privado y ejecutará los trabajos configurados. Massive proporciona los datos de mercado. Cada servicio aplica sus propias condiciones y políticas.

El proyecto no vende información de Google ni la utiliza para publicidad. El uso y la transferencia de información recibida de las APIs de Google se ajustarán a la política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado.

El proyecto no utiliza información obtenida de Google Workspace para desarrollar, mejorar o entrenar modelos generales de inteligencia artificial. El motor Python no utiliza una API de OpenAI. Si el usuario solicita revisar una hoja en ChatGPT mediante su conexión de Drive, ese acceso depende de su autorización y de la configuración y condiciones de dicho servicio.

Conservación y control

Los archivos del proyecto se conservan para mantener el histórico de trabajo y permitir su recuperación. La política de conservación local y remota se configurará con límites de tamaño. Actualmente no se ejecuta un borrado automático del histórico original.

El usuario puede revocar el acceso en las conexiones de su cuenta Google. Revocar la autorización impide accesos posteriores, pero no elimina automáticamente los archivos existentes. Puede borrar los archivos desde Drive y retirar las credenciales locales y los secretos de GitHub.

Esta web y contacto

Estas páginas son informativas y no contienen formularios, analítica ni scripts de seguimiento propios. El proveedor que las aloje puede tratar registros técnicos de navegación conforme a su política.

Para consultas sobre privacidad, utiliza el correo de asistencia mostrado por Google en la pantalla de consentimiento de IBKR Swing Scanner. El texto se actualizará cuando cambie el tratamiento de datos del proyecto.
